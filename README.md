# Thaumic Energistics Extended Life
*Because the digital age could use some magic!*

## About

This is a fork maintained to keep Thaumic Energistics compatible with [Applied Energistics 2 Supergiant][ae2s].

*Cleanroom* is a 1.12.2 Forge fork, providing newer toolchain, new APIs and 99% compatibility.It needs Java 25.

The aim of this mod is to serve as a bridge between Thaumcraft and Applied Energistics with a primary focus is essentia management: storage, transportation, and application.

Built for Minecraft 1.12.2

## Requirements

*Cleanroom* is required.

The following mods are also required:

* Thaumcraft
* Applied Energistics 2 Supergiant

This is now currently based off [Applied Energistics 2 Supergiant][ae2s] and depends on *Cleanroom*. Therefore, regular AE2 and AE2 uel is not compatible with this mod.

## API

Thaumic Energistics provides an API similar to the AE2 API. Check `src/main/java/thaumicenergistics/api` for more API info.
